Automated Job Ingestion Engine: Setup Guide

This system queries the open, keyless REST APIs of Greenhouse, Lever, and Ashby directly on a scheduled cron via GitHub Actions. No paid scraper services, no proxies, and no server bills.

[GitHub Actions Cron (Every 6h)] ➔ [fetch_jobs.py] ➔ [Public ATS APIs (Greenhouse/Lever)] ➔ [jobs.json updated in Git] ➔ [GitHub Pages / Vercel Live UI]

Step 1: Download the Automation Files

The complete packaged crawler code and GitHub Actions workflow are available in the deliverable zip file: job_tracker_automation.zip.

Step 2: Push to a Free GitHub Repo

Create a free public or private GitHub repository, place the files inside, and commit them:

git init
git add .
git commit -m "feat: initial product company job tracker"
git branch -M main
git remote add origin https://github.com/<your-username>/product-job-radar.git
git push -u origin main

Step 3: Enable Free GitHub Pages

Go to your Repository Settings ➔ Pages ➔ Select Branch: main / root ➔ Click Save. Your job board is live on the internet forever for $0.
